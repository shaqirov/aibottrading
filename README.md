# AI Bot Trading

Бот для свинг-трейдинга криптовалют (спот, только покупки, таймфрейм 4h), который
торгует по правилам опытного трейдера и спрашивает «второе мнение» у ИИ перед каждой сделкой.

## Как бот принимает решение

```
Режим рынка (раз в сутки) ─┐
                           ▼
Свечи + новости → Правила ──сигнал──→ ИИ проверяет ─┐
                  └─молчат─→ ИИ ищет сделку сам ──┤
                                                   ▼
                              Риск-менеджер → Ордер → ИИ сопровождает позицию → Журнал
```

**Правила** (`bot/strategy.py`): покупка отката в восходящем тренде.
Цена выше EMA200, EMA20 > EMA50, свеча коснулась EMA20 и закрылась выше, RSI 40–65.
Стоп = 2×ATR ниже входа, тейк = 2.5× риска.

**ИИ-аналитик** (`bot/analyst.py`) — «опытный трейдер» в четырёх ролях:

| Роль | Когда | Что решает |
|---|---|---|
| 1. Проверка сигналов | при сигнале правил | одобрить / отклонить, подтянуть стоп |
| 2. Сопровождение позиций | раз в 4h-свечу на позицию | держать / подтянуть стоп / закрыть досрочно |
| 3. Режим рынка | раз в сутки, по BTC и новостям | trend_up / range / trend_down / panic → множитель риска 0..1 |
| 4. Поиск сделок | когда правила молчат, не чаще раза в 12 ч на монету | своя идея: вход, стоп, тейк |

ИИ получает 4h и дневные свечи с индикаторами и свежие новости по монете
(`bot/news.py`: RSS CoinDesk/Cointelegraph, при наличии токена — CryptoPanic).

**Ограничения ИИ** (проверяются кодом):
- не может отодвинуть стоп дальше от цены или увеличить риск — только уменьшить;
- идея ИИ проверяется: стоп в 0.5–4 ATR от цены, прибыль/риск ≥ 2, и торгуется половинным риском,
  потому что такие сделки нельзя проверить бэктестом;
- при панике (`risk_multiplier: 0`) новые сделки не открываются;
- при ошибке или низкой уверенности ИИ (< 0.6) выбирается безопасный вариант;
- без ИИ режим рынка определяется по правилу: BTC выше/ниже дневной EMA200.

**Риск-менеджер** (`bot/risk.py`): 1% капитала на сделку (× множители), позиция ≤ 30% капитала,
не больше 3 позиций, стоп на день при −3%, пауза 48 ч после 4 убытков подряд.

**Сопровождение**: после +1R стоп переносится в безубыток; выход по стопу, тейку, слому тренда или решению ИИ.

**Журнал** (`data/journal.csv`): режим рынка, сигналы, идеи ИИ, решения по позициям с обоснованиями, результаты сделок.

Все роли ИИ включаются и выключаются в разделе `llm` файла `config.yaml`.

## Установка

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполните ключи: LLM_API_KEY, LLM_BASE_URL, LLM_MODEL
```

## Запуск

```bash
python -m bot backtest --days 730   # проверка правил на истории за 2 года
python -m bot once                  # один цикл
python -m bot run                   # постоянная работа (лучше на VPS)
```

По умолчанию `mode: paper` — виртуальный баланс 1000 USDT и реальные цены.
Состояние хранится в `data/paper_state.json`.

## Переход на реальные деньги

1. Минимум 1–3 месяца в режиме `paper` с положительным результатом.
2. Создайте API-ключ на бирже **только с правом торговли, без вывода**, по возможности с привязкой к IP.
3. Пропишите ключи в `.env`, поставьте `mode: live` в `config.yaml`, начните с небольшой суммы.

Стопы отслеживает сам бот (рыночный ордер при касании), поэтому он должен работать постоянно.

## Предупреждение

Торговля связана с риском потери средств. Бот — инструмент, а не гарантия прибыли.
Прошлые результаты бэктеста не гарантируют будущих.

## Расходы на ИИ

Примерно 300–600 запросов в месяц на 3 монеты (в основном поиск сделок и сопровождение).
Чтобы снизить расходы — увеличьте `scan_every_hours` или выключите `scanner`.
