# AI Bot Trading

Бот для свинг-трейдинга криптовалют (спот, только покупки, таймфрейм 4h), который
торгует по правилам опытного трейдера и спрашивает «второе мнение» у ИИ перед каждой сделкой.

## Как бот принимает решение

```
Свечи с биржи → Стратегия (правила) → ИИ-аналитик → Риск-менеджер → Ордер → Журнал
```

1. **Стратегия** (`bot/strategy.py`): покупка отката в восходящем тренде.
   Цена выше EMA200, EMA20 > EMA50, свеча коснулась EMA20 и закрылась выше, RSI 40–65.
   Стоп = 2×ATR ниже входа, тейк = 2.5× риска.
2. **ИИ-аналитик** (`bot/analyst.py`): получает сигнал, 4h и дневные свечи,
   оценивает сделку как опытный трейдер и отвечает JSON (одобрить/отклонить, уверенность, причины).
   ИИ может только *отклонить* сделку или *подтянуть* стоп — увеличить риск он не может.
   При ошибке ИИ сделка не открывается.
3. **Риск-менеджер** (`bot/risk.py`): 1% капитала на сделку, позиция ≤ 30% капитала,
   не больше 3 позиций, стоп на день при −3%, пауза 48 ч после 4 убытков подряд.
4. **Сопровождение**: после +1R стоп переносится в безубыток; выход по стопу, тейку или слому тренда.
5. **Журнал** (`data/journal.csv`): каждый сигнал, решение ИИ с обоснованием и результат сделки.

## Установка

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполните ключи
```

## Запуск

```bash
python -m bot backtest --days 730   # проверка правил на истории за 2 года
python -m bot once                  # один цикл
python -m bot run                   # постоянная работа (лучше на VPS)
```

По умолчанию `mode: paper` — виртуальный баланс 1000 USDT и реальные цены.
Состояние хранится в `data/paper_state.json`.

## Переход на реальные деньги

1. Минимум 1–3 месяца в режиме `paper` с положительным результатом.
2. Создайте API-ключ на бирже **только с правом торговли, без вывода**, по возможности с привязкой к IP.
3. Пропишите ключи в `.env`, поставьте `mode: live` в `config.yaml`, начните с небольшой суммы.

Стопы отслеживает сам бот (рыночный ордер при касании), поэтому он должен работать постоянно.

## Предупреждение

Торговля связана с риском потери средств. Бот — инструмент, а не гарантия прибыли.
Прошлые результаты бэктеста не гарантируют будущих.
